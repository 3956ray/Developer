# 思 · thinkV2

从独立空白 Android 模板开发的本地笔记应用。当前任务为 `V2-NOTES-ACCESSIBILITY-001`；文字核心、分类、回收站、提醒与备份已验收。离线语音已接入，识别质量验收尚未通过。

当前范围见 [分类与回收站合同](doc/lifecycle-requirements.md)，上一单文字范围见 [需求基线](doc/requirements.md)。实现位于 `app/src/main/java/com/example/thinkv2/notes`。

## 使用路径

- 首页「新增文字」→ 输入正文/可选分类 → 保存。
- 点击真实笔记即可编辑；标题默认为正文首句，可手改或恢复自动标题。
- 编辑500ms空闲后保存草稿；返回保留草稿，放弃编辑需要确认。
- 首页输入标题或正文关键词搜索；空白分隔的多个词需同时匹配。

已保存笔记可设置一次、每天或每周多个选日的本地提醒；首页可查看提醒计划和触发记录。提醒采用系统非精确调度，可能延迟；通知权限关闭时会保留规则并显示未启用。

首页「备份与恢复」可通过系统文件选择器导出明文备份、预览并合并恢复；冲突默认保留本机并另存副本，导入提醒保持关闭，AI需本机重新确认。v2覆盖纠错词表、日历来源、已接受AI来源与关系，凭据和音频不导出；旧v1文件缺失这些字段会在预览说明。请将备份保存到安全位置，选择云盘可能上传文件。

编辑器可按住说话、松手处理，将离线中文转写插入当前草稿；可取消，单次最长90秒。原始音频只在内存处理。识别效果仍待改进，专名尤其需要核对；纠错词表仅在转写后提供确认建议，不改变原始识别。v2备份包含纠错词表。

上一单Vosk冻结合成30段测试的原始专名正确率为47/66（71.21%），严格工程可用性10/30，均未达要求，因此语音不能宣称完整验收。具体证据与剩余条件见[语音验证记录](doc/voice-verification.md)。

首页「从日历导入」可选择一个源日历和最多366天范围，预览、选择分类和事件后确认导入。只请求读取权限，保留原始来源快照，重复导入跳过已有版本；来源变更默认跳过，可明确另建副本。本机提醒不会自动开启。v2备份包含日历原始快照与去重映射；恢复后相同源版本再次导入会跳过。见[日历导入验证记录](doc/calendar-import-verification.md)。

AI标题/分类建议默认关闭；在「AI建议设置」填写HTTPS端点、模型和凭据并确认供应商后，编辑器可逐次预览必要文字及候选分类，再明确发送。建议分别接受/修改/拒绝，不自动改正文或建分类。真实供应商尚未配置验证（provider_verified=false）；当前只完成合成服务工程验证。见[AI建议验证记录](doc/ai-suggestions-verification.md)。

已保存笔记的编辑器可打开「相关笔记」，明确选择另一条真实笔记建立双向关系，或确认移除关系。每页最多50条，可搜索、翻页和按稳定ID打开；回收站中的端点暂时隐藏，恢复后原关系重新显示。v2备份包含关系及端点映射。见[关系验证记录](doc/relations-verification.md)。

编辑器可明确进入「命令模式」，只识别“新建笔记／保存当前草稿／取消本次输入”，显示识别结果并要求确认。普通口述中的相同短语仍是正文；新建先保留原草稿，保存拒绝空正文，取消不删此前文字。见[语音控制验证](doc/voice-controls-verification.md)。可选图谱尚未实现。本版本不代表小米15或家庭试用已通过。

构建和验证的实际命令与结果见 [语音验证记录](doc/voice-verification.md)。真机/家庭试用尚未验证。

笔记首页、分类与回收站支持整体滚动，关系操作以标题、分类和摘要区分记录；大字体/明暗主题与键盘焦点验证见[可读性与无障碍报告](doc/notes-accessibility-verification.md)。实际TalkBack导航仍有未验证缺口。

正式完整产品范围：[2026-09-16独立产品基线](doc/product-baseline-decision-2026-09-16.md)。当前可在编辑器把笔记移入回收站，并在首页回收站恢复原记录；没有永久删除。分类管理支持创建、改名和确认删除分类，笔记内容保留。

历史语音结果见 [语音验证记录](doc/voice-verification.md)，运行对象审查见 [运行库与模型审查](doc/voice-runtime-review.md)。[CP8兼容验证报告](doc/backup-compatibility-verification.md)、[早期备份验证报告](doc/backup-verification.md)、[备份格式](doc/backup-format.md)、[提醒验证报告](doc/reminders-verification.md)及早期报告保留为历史证据。
